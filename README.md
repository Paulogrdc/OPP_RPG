# 🛡️ RPG em Python

Projeto desenvolvido em **Python** com o objetivo de aplicar os fundamentos da **Programação Orientada a Objetos (POO)** na construção de um jogo de RPG em modo texto.

O projeto foi desenvolvido como parte dos meus estudos em desenvolvimento de software, colocando em prática conceitos de modelagem de classes, organização de código e lógica de programação por meio de uma aplicação interativa executada no terminal.

## 🎮 Funcionalidades

Ao iniciar o jogo, o jogador encontra um menu com as seguintes opções:

### ⚔️ Escolher personagem

É possível escolher entre duas classes de personagem:

* Guerreiro
* Mago

Cada personagem possui seus próprios atributos e características.

### 📊 Ver status do personagem

Exibe as informações atuais do personagem selecionado:

* Nome
* Categoria
* Nível
* Vida

### 🛡️ Batalhar

Permite enfrentar inimigos para ganhar experiência e evoluir o personagem.

O personagem pode evoluir até o **nível 20**. Ao atingir esse nível, o jogador vence o jogo e a partida é encerrada.

### 🚪 Sair do jogo

Finaliza a execução da aplicação.
